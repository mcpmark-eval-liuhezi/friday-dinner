# friday-dinner

本仓库用于存放我们组**周五团队晚餐**的菜单与购物清单，方便同事预览、定稿与归档。

## 用途

- 发布每周团队晚餐的菜单草稿（`menu-draft.md`），供全组预览和反馈
- 定稿后归档最终菜单与购物清单（`MENU.md`）
- 作为团队晚餐信息同步的单一来源，与办公室展示集群保持一致

## 本周用餐信息

- **人数**：6 人
- **忌口**：一位同事对虾过敏（严格避开虾及虾制品）；两位同事不吃香菜；另避开羊肉
- **指定主食**：手抓饼（组内点名）

## 菜谱来源

所有菜谱均来自开源项目 [HowToCook](https://github.com/Anduin2017/HowToCook)（程序员在家做饭指南）。
